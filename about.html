About This Project

This website was created for IT 3203: Web Development at Kennesaw State University. The project explores how web design has evolved from the 1990s to the present day.

The website covers major design trends, important web technologies, and the transition from early static websites to modern responsive interfaces.

Project Goals

  • Explore the history of web design
  • Practice creating webpages with HTML
  • Use CSS to create consistent styling
  • Build a responsive website
  • Learn how to publish using GitHub Pages

This website is a class project for IT 3203 Web Development .
